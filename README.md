A small program that writes one sentence (195 characters) to `/output/entry.txt`: a startup pitch for renting hungry goats to clear overgrown land — homeowners and solar farms pay, because the herd eats weeds a mower can't reach, needs no fuel, and fertilizes the ground as it works.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only; the output is byte-identical on every run.
